# Генератор отчётов по рынку недвижимости с использованием Gemini API

Этот проект представляет собой веб-приложение на базе FastAPI, предназначенное для автоматизированной генерации DOCX-отчётов по анализу рынка недвижимости. Генерация текста осуществляется с помощью модели Gemini от Google, данные берутся из структурированного JSON-файла.

## 🚀 Возможности

- Загрузка JSON-файла с характеристиками объекта и рыночными данными
- Генерация отчёта в формате `.docm` по заданной структуре
- Поддержка вставки изображений из base64 в документ
- Актуализация оглавления и обтекание изображений текстом
- Ограничение количества запросов к Gemini API (rate limiting)
- Автоматическое скачивание готового отчёта на клиенте

## 🧱 Стек технологий

- Backend: Python 3.12+, FastAPI
- Frontend: HTML, JavaScript
- AI: Gemini API (Google Generative AI)
- Форматирование: python-docx, win32com (для макросов)
- Хранение данных: JSON

## 📂 Структура проекта

├── app.py                  # основной файл FastAPI-приложения
├── input.json              # входные данные (загружаются пользователем)
├── report_structure.json   # структура отчёта (заголовки, промпты, пути к данным)
├── static/
│   └── index.html          # клиентская часть (форма загрузки и генерации)
├── reports/                # папка для сохранения отчётов
├── requirements.txt        # зависимости проекта
├── pyproject.toml          # информация о проекте и версия Python
├── .env                    # файл с API-ключом Gemini
└── README.md               # этот файл

## ⚙️ Установка и запуск

1. Убедитесь, что у вас установлен Python 3.12+ и pip.

2. Клонируйте репозиторий и установите зависимости:

pip install -r requirements.txt

3. Укажите API-ключ Gemini в `.env`:

GEMINI_API_KEY=ваш_ключ

4. Запустите сервер:

uvicorn app:app --reload

5. Перейдите в браузере по адресу:

http://127.0.0.1:8000/

## 📦 Обновление зависимостей

Если вы добавили новые библиотеки, обновите `requirements.txt` командой:

pip freeze > requirements.txt
